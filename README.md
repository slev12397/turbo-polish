# Turbo Polish

Turbo's taste, design system, motion and polish rules for building AI-native product UI. Written for designers and coding agents.

Start at [`SKILL.md`](SKILL.md).

| File | What |
| --- | --- |
| `taste.md` | What good looks like |
| `design-system.md` | What to build with |
| `motion.md` | How it moves |
| `polish.md` | Polish rules by ID, and the review pass |
| `clients/` | Per-client brand values and product rules |

## Use it as a skill

Copy or symlink this folder into `.claude/skills/turbo-polish/` (or your agent's skills folder), or point a project's `AGENTS.md` at `SKILL.md`.
